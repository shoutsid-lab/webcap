# webcap Marketing Metrics Framework

## Overview

This document defines the key metrics to track marketing effectiveness and ROI for webcap. All metrics should be tracked weekly and reported monthly.

## Primary Business Metrics

### Revenue Metrics
- **MRR (Monthly Recurring Revenue):** Target £1,000 in 90 days
- **ARR (Annual Recurring Revenue):** Target £12,000 in 90 days
- **Average Revenue Per User (ARPU):** Target £10/month
- **Customer Lifetime Value (LTV):** Target £500 (based on 50-month retention)

### Customer Metrics
- **Total Customers:** Target 100 in 90 days
- **Paying Customers:** Target 100 in 90 days
- **Free Preview Users:** Target 1,000 in 90 days
- **Conversion Rate (Free → Paid):** Target 5%
- **Customer Acquisition Cost (CAC):** Target < £50

### Growth Metrics
- **MRR Growth Rate:** Target 20% week-over-week
- **Customer Growth Rate:** Target 20% week-over-week
- **Net Revenue Retention:** Target > 100%
- **Churn Rate:** Target < 5% monthly

## Channel-Specific Metrics

- **Upvotes:** Target 500+ on launch post
- **Comments:** Target 50+ meaningful discussions
- **Traffic:** Target 1,000+ unique visitors from HN
- **Signups:** Target 50+ free preview users from HN
- **Conversions:** Target 5+ paying customers from HN

- **Upvotes:** Target 100+ total upvotes
- **Comments:** Target 20+ meaningful discussions
- **Traffic:** Target 500+ unique visitors from Reddit
- **Signups:** Target 25+ free preview users from Reddit
- **Conversions:** Target 3+ paying customers from Reddit

### Dev.to
- **Articles:** Target 3 technical articles
- **Views:** Target 1,000+ total views
- **Likes:** Target 50+ total likes
- **Comments:** Target 20+ comments
- **Traffic:** Target 300+ unique visitors from Dev.to
- **Signups:** Target 15+ free preview users from Dev.to
- **Conversions:** Target 2+ paying customers from Dev.to

### Twitter/LinkedIn
- **Followers:** Target 100+ new followers
- **Engagement:** Target 50+ retweets/likes
- **Traffic:** Target 200+ unique visitors
- **Signups:** Target 10+ free preview users
- **Conversions:** Target 1+ paying customer

### Direct Outreach
- **Messages Sent:** Target 50+ direct messages
- **Response Rate:** Target 20% response rate
- **Meetings Booked:** Target 10+ meetings
- **Conversions:** Target 5+ paying customers

## Funnel Metrics

### Top of Funnel (Awareness)
- **Website Traffic:** Target 2,000+ unique visitors/month
- **Page Views:** Target 5,000+ page views/month
- **Bounce Rate:** Target < 60%
- **Time on Site:** Target > 2 minutes

### Middle of Funnel (Consideration)
- **Free Preview Usage:** Target 1,000+ users/month
- **API Calls (Free):** Target 10,000+ calls/month
- **Documentation Views:** Target 500+ views/month
- **Blog/Content Views:** Target 1,000+ views/month

### Bottom of Funnel (Conversion)
- **Signups:** Target 100+ new users/month
- **Activation Rate:** Target 30% of signups make first API call
- **First Payment:** Target 10% of activated users make first payment
- **Repeat Purchase:** Target 50% of first-time buyers make second purchase

### Retention Metrics
- **30-Day Retention:** Target 40% of paying customers
- **60-Day Retention:** Target 30% of paying customers
- **90-Day Retention:** Target 25% of paying customers
- **Monthly Churn:** Target < 5%

## Content Performance Metrics

### Blog/Articles
- **Views:** Target 1,000+ views per article
- **Read Time:** Target > 3 minutes average
- **Shares:** Target 10+ shares per article
- **Comments:** Target 5+ comments per article
- **Conversion Rate:** Target 2% of readers sign up

### Social Media
- **Engagement Rate:** Target > 5% on posts
- **Click-Through Rate:** Target > 2% on links
- **Follower Growth:** Target 10% month-over-month
- **Mentions:** Target 10+ mentions per month

### Email (Future)
- **Open Rate:** Target > 20%
- **Click-Through Rate:** Target > 5%
- **Unsubscribe Rate:** Target < 1%
- **Conversion Rate:** Target > 3%

## ROI Metrics

### Cost Metrics
- **Content Creation Cost:** Target £500/month
- **Paid Promotion Cost:** Target £200/month
- **Tools Cost:** Target £100/month
- **Total Marketing Cost:** Target £800/month

### Return Metrics
- **Marketing ROI:** Target > 500% (MRR / Marketing Cost)
- **CAC Payback Period:** Target < 5 months
- **LTV:CAC Ratio:** Target > 10:1
- **Revenue per Marketing Pound:** Target £6+ per £1 spent

### Channel ROI
- **HN ROI:** Target > 1000%
- **Reddit ROI:** Target > 800%
- **Dev.to ROI:** Target > 600%
- **Twitter/LinkedIn ROI:** Target > 400%
- **Direct Outreach ROI:** Target > 1000%
